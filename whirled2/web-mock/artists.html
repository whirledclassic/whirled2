What this is

Whirled 2 is a new browser world in the spirit of Whirled (2007–2017): your room, walk-around avatars, user-made stuff. No Flash. No ripped old shop items.

The website chrome lives in this repo. The room engine is separate. Artists ship into assets/, not into engine source.

Style target: high-contrast, readable at game scale. Editorial toybox, not casino gacha, not emoji sticker pack. UI chrome should feel like classic whirled.com (blue header, swirl, tabs) — not a different brand skin.

What you are getting into

Paid work is on the table. Volunteer work is also on the table. You choose on the form below. Josh reads the application, the portfolio, and — if you picked paid — the number you wrote.

Volunteer — credit and a seat on the project. No invoice.

Paid — you name a price for the first drop. A yes is a written yes for that drop. It is not a salary and not a retainer unless we later agree to that in writing.

Want to stay on long-term? Say so. For now, long-term still means one-time payments per asset batch. We ship a drop, we pay for that drop, we stay in touch, we do the next drop the same way.

Either track: credit in the repo and on a credits screen when one exists. Applying is not a hire. Shipping a file is not a paycheck until that drop is agreed.

Original work only. No original Whirled shop items or ripped Flash assets. You can show shipped work in your portfolio. We need a license we can actually use (repo license, CC-BY, or a short written grant).

Roles — apply for the ones you actually do

Avatar artist

One humanoid (or readable creature) that works in a room.

  • Idle + 4-direction walk
  • Consistent pixel size / pivot
  • Optional: sit, wave, talk

Room / environment

A walkable space, not a painting.

  • Floor + backdrop or two walls
  • Collision-friendly layout
  • First need: one complete room (Studio Loft energy)

Furniture / props

Things you can place in a room.

  • Chair, table, plant, lamp first
  • 4–8 pieces, same scale as the avatar
  • Clean edges, readable silhouette

UI / chrome

Buttons, tabs, panels, icons for the website shell.

  • Me / Stuff / Games / Rooms / Groups / Shop feel
  • Must match classic blue Whirled chrome
  • SVG or crisp PNG @1x and @2x

Shop / item art

Wearables, toys, badges — new originals only.

  • Icon + in-world view if it sits in a room
  • No copies of old catalog SKUs

Animator

If you can take a still sheet and make it walk.

  • Sprite sheets or short loops
  • Frame list + pivot notes

Music / SFX

Original loops and tiny UI sounds.

  • Room ambience, click, chat ping
  • No copyrighted samples you cannot grant

Something else

Logo lockups, loading screens, marketing stills, pixel fonts. Say it on the form.

How files should arrive

  • PNG or SVG for stills. Sprite sheets with a short text note (frame size, rows, pivot).
  • Zip or a folder link (Google Drive / Dropbox / GitHub). No 400 MB Photoshop files as the only copy.
  • Name files like avatar-idle-s.png, not finalFINAL2.png.
  • One job per drop. A walk cycle is one drop. A whole world is not a first drop.
