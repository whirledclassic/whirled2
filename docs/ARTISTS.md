# Artist terms

Short version so nobody gets baited.

**Now:** volunteer / free. No contract hours. No guaranteed paycheck.

**Later:** if Whirled 2 makes money, Josh pays from that money for work that shipped into the live world. Ship alone is not a paycheck. No money in = no pay.

**Either way:** credit in the repo and in the client when there is a credits screen.

## What we need first

- One walkable room: floor, two walls or a backdrop, collision-friendly layout
- 4–8 furniture props (chair, table, plant, lamp)
- One humanoid avatar, idle + 4-direction walk, consistent pixel size

Style target: high-contrast, readable at game scale. Not purple-gold casino, not emoji sticker pack. Think editorial toybox, not gacha.

## How to submit

Open a GitHub issue. Attach a zip or a link. Say whether we can ship it under the repo license (see LICENSE) or you want a separate grant (CC-BY is fine).

Do not send original Whirled shop items.
